# Issue tracker: GitHub

Issues and specs live in this repository's GitHub Issues. Use `gh` for all operations.

Pull requests are not a triage request surface.

## Wayfinding operations

- A map is an issue labelled `wayfinder:map`.
- Tickets are child issues labelled `wayfinder:research`, `wayfinder:prototype`, `wayfinder:grilling`, or `wayfinder:task`.
- Prefer native GitHub sub-issues and issue dependencies.
- If unavailable, use map task lists and `Blocked by:` body lines.
- Claim a ticket by assigning it before beginning work.
- Resolve it with an answer comment, close it, then append a linked gist to the map.
