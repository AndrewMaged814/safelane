# SafeLane coordinates; Argo executes

SafeLane owns assessment, the frozen Safety Contract, progression authority, reconciliation, and proof; Argo Rollouts owns Analysis Job evaluation, traffic mechanics, normal-path abort, and rollback. SafeLane may request the next already-authorized progression after Argo reports success, but its normal Release Run never aborts in response to analysis failure—doing so would create two competing rollback authorities. Explicit emergency controls remain a separate, audited path.
